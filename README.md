# Super Snake 3000

A simple snake game made with just HTML, CSS, JS, and jQuery.

## Game Modes

- **Survival** - Survive for as long as possible in one of three dificulty options.

## Tech Stack

- HTML
- CSS
- JS
- [JQuery](https://jquery.com/)
